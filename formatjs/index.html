How to use this tool / 使用说明

Use this page for readable formatting, quick cleanup, and inspecting copied JavaScript snippets. It does not guarantee the code is safe or valid in every runtime.

If code has missing braces, broken strings, or unsupported syntax, formatting may be incomplete.

Privacy note / 隐私说明

Most text, encoding, hashing, and formatting actions on this page run in your browser. Avoid pasting secrets, production credentials, private keys, or sensitive personal data into any online tool.
