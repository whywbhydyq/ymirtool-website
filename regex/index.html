How to use this tool / 使用说明

Enter the pattern without wrapping slashes, choose the flags you need, paste sample text, and click Test Regex.

This page uses the browser JavaScript RegExp engine, so patterns may behave differently from PCRE, Python, Java, or database regex implementations.

Usage notes / 使用说明

Test positive examples, negative examples, empty strings, Unicode text, and multiline text before moving a regular expression into production code.

FAQ / 常见问题

Which regex engine is used?

The browser JavaScript RegExp engine is used. Server-side languages may support different syntax or flags.

Why does a server regex behave differently?

Different languages use different regex engines. Check escaping, Unicode support, multiline behavior, and unsupported constructs.

Should I test only matching examples?

No. Also test examples that should not match, empty input, and edge cases near the beginning and end of the text.
