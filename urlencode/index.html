How to use this tool / 使用说明

Use encodeURIComponent for query parameter values and encodeURI for full URLs. Decoding invalid percent sequences will show an error instead of breaking the page.

This is useful when building links, debugging redirect URLs, or checking query strings that contain spaces or non-Latin characters.

Privacy note / 隐私说明

Most text, encoding, hashing, and formatting actions on this page run in your browser. Avoid pasting secrets, production credentials, private keys, or sensitive personal data into any online tool.

FAQ / 常见问题

encodeURI or encodeURIComponent?

Use encodeURIComponent for a single query value; use encodeURI for a full URL.

Why does decode fail?

The input may contain an incomplete percent escape such as %E4 without the remaining bytes.

Does it run locally?

Yes. Encoding and decoding happen in your browser.
