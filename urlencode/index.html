How to use this tool / 使用说明

Paste a full URL when you need to keep the URL structure, or paste one query parameter value when you only need to encode a single value.

Use Encode URI Component for query values such as names, search terms, and redirect parameters. Use Encode URI for a full URL that already contains protocol and slashes.

Usage notes / 使用说明

Do not paste access tokens, private redirect links, production credentials, or personal data unless you are comfortable processing that text in an online tool.

FAQ / 常见问题

encodeURI or encodeURIComponent?

Use encodeURIComponent for a single query value. Use encodeURI for a full URL when you want to keep characters such as :, /, and ? readable.

Why does decode fail?

The input may contain an incomplete percent escape, such as %E4 without the remaining bytes, or text that was copied only partially.

What should I paste here?

Paste only the URL, query string, or value you want to encode or decode. Avoid pasting secrets, tokens, or private credentials.
