How to use this tool / 使用说明

GUIDs are commonly used as identifiers for tests, records, sample data, and development workflows.

The generated values are suitable for general identifier use but should not be treated as authentication secrets.

Privacy note / 隐私说明

Most text, encoding, hashing, and formatting actions on this page run in your browser. Avoid pasting secrets, production credentials, private keys, or sensitive personal data into any online tool.

FAQ / 常见问题

Is this generated locally?

Yes. It uses browser crypto.randomUUID when available, with a fallback for older browsers.

Can I generate multiple GUIDs?

Yes. Set the count up to 100.

Is a GUID a password?

No. GUIDs identify things; passwords protect access.
