RC4 Legacy Compatibility Reference

Reference-only guidance for identifying and retiring RC4 dependencies. Runtime encryption and decryption are disabled.

  • Use RC4 only to reproduce or inspect legacy formats.
  • RC4 Legacy Compatibility Reference: Paste non-sensitive sample data first; do not paste secrets, tokens, customer data, or production keys.
  • RC4 Legacy Compatibility Reference: For new security-sensitive work, use a reviewed modern cryptographic design outside this compatibility helper.

RC4 is a migration target, not a design option

Runtime execution is disabled. RC4 has known statistical weaknesses, and RC4 cipher suites are prohibited in TLS. Preserve only enough non-sensitive information to identify the legacy dependency and replace it.

  • Record the library, key material source, drop/discard behavior, and ciphertext encoding.
  • Do not generate new RC4 test data when an existing fixture can be used.
  • Replace transport use with a currently supported TLS configuration and application data with an authenticated cipher.

Standards reference

See RFC 7465: Prohibiting RC4 Cipher Suites.
