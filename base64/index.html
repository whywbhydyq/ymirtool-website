How to use this tool / 使用说明

Base64 is useful for representing text or small data snippets in a transport-safe form. It does not hide secrets and should not be treated as encryption.

UTF-8 text is supported, including Chinese characters, emoji, and mixed punctuation.

Privacy note / 隐私说明

Most text, encoding, hashing, and formatting actions on this page run in your browser. Avoid pasting secrets, production credentials, private keys, or sensitive personal data into any online tool.

FAQ / 常见问题

Is Base64 secure?

No. Anyone can decode Base64. Do not use it to protect passwords or secrets.

Why does decoding fail?

The input may contain invalid Base64 characters, missing padding, or binary data that is not UTF-8 text.

Does it run locally?

Yes. Encoding and decoding happen in your browser.
