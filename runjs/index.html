Use cases and limits

Use this tool to preview small standalone snippets, demos, examples, or documentation code. The runtime uses an iframe sandbox and a restrictive CSP, so it is not equivalent to a full browser dev server.

Safe use note

Do not run untrusted production code or secrets. The preview is isolated, but browser behavior, mixed content rules, and CSP limits can affect snippets.
