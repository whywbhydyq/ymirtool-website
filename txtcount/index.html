How to use this tool / 使用说明

This tool is useful for writing limits, metadata drafts, social posts, descriptions, translation work, and quick text cleanup.

Word counting is approximate for mixed-language text. Character and byte counts are deterministic.

Privacy note / 隐私说明

Most text, encoding, hashing, and formatting actions on this page run in your browser. Avoid pasting secrets, production credentials, private keys, or sensitive personal data into any online tool.

FAQ / 常见问题

Does it count Chinese words?

It counts characters reliably. Word count is approximate for languages without spaces.

Does it update live?

Yes. Statistics update as you type.

Does the text leave my browser?

No. Counting runs locally in your browser.
