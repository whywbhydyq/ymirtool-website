How to use this tool / 使用说明

Paste or type text into the input box. The character, word, line, paragraph, and byte counts update as the text changes.

Use the summary when checking metadata drafts, social posts, descriptions, translation work, or writing limits.

FAQ / 常见问题

Does it count Chinese words?

It counts Chinese characters reliably. Word count is approximate for languages that do not separate words with spaces.

Does it update live?

Yes. The statistics update as you type or paste text.

Why do byte counts differ from character counts?

Characters can use different numbers of bytes depending on encoding. Non-ASCII characters usually require more than one byte.
