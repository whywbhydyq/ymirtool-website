如何从指南进入正确工具

指南中心按任务组织，而不是按工具数量组织。遇到接口响应、编码失败、时间戳错位、文本差异或正则匹配异常时，先阅读对应指南，确认输入格式、边界条件和复核步骤，再打开工具页执行具体操作。

  • 结构化数据：从 JSON 指南开始，先排除注释、尾逗号、引号和 HTML 错误页，再进入 JSON 格式化器。
  • 编码转换：从 Base64 或 URL 编码指南开始，区分编码、转义、加密和传输场景。
  • 发布复核：从文本对比、复制安全和正则复核专题开始，记录原始输入、工具输出和目标系统要求。

如果任务涉及密钥、Cookie、访问令牌、内部接口地址或客户数据，应先脱敏或改用团队批准的内部工具。
