Apache htpasswd Compatibility Generator

Generate legacy Apache password-file entries for compatibility tests. Create new credentials server-side with htpasswd -B and bcrypt.

Legacy formats in this browser helper

The included compatibility library can emit $apr1$ MD5, {SHA}, traditional crypt, or plain entries. These choices exist to reproduce historical files; they are not the preferred way to create new credentials.

  • For new Apache credentials, run htpasswd -B on the server to create a bcrypt entry.
  • Do not paste a real administrator or production password into this page.
  • Test generated compatibility lines only in a disposable local fixture.

Server-side source of truth

Apache documents the supported password-file formats and warns about weaker historical schemes. Review the htpasswd program documentation and Apache password formats before changing a live server.
