Seconds, milliseconds, and timezones

Unix timestamps are commonly represented in seconds or milliseconds. Ten-digit values are usually seconds; thirteen-digit values are usually milliseconds.

Readable local dates use your device timezone display. ISO output is UTC and is often safer for logs, APIs, and cross-system debugging.

FAQ

Seconds or milliseconds?

Many server logs use seconds, while JavaScript Date.now() uses milliseconds. The converter detects common 10-digit and 13-digit values.

Which timezone is used?

The readable local date uses your device timezone display; the ISO output is UTC.

Can I copy the current timestamp?

Yes. Load the current time, then copy seconds, milliseconds, or the converted result.
