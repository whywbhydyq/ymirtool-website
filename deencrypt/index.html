Use cases and limits

Encrypt or decrypt DES text with a passphrase. DES is legacy and should only be used for compatibility checks. Legacy encryption helpers are intended for format compatibility, testing, and migration support. Do not treat browser tools as a replacement for a reviewed security architecture.

Safe use note

Review outputs before use. Avoid pasting real private keys, production secrets, tokens, customer records, or sensitive internal data into any online tool.
