适合联系我们的情况

  • 工具在某个浏览器或设备上无法使用，按钮无响应，复制结果异常或输出不符合说明。
  • 页面示例、错误表、FAQ、隐私边界或技术说明存在不准确之处。
  • 发现断链、错误 canonical、sitemap 问题、移动端排版异常或无障碍问题。
  • 对广告展示、Cookie、第三方服务或隐私政策有疑问。
  • 希望建议新增工具、补充案例、增加排错流程或改进指南中心导航。

请不要发送敏感资料

请勿在邮件中发送密码、API Token、私钥、认证 Cookie、客户资料、生产数据库导出、未公开源代码或完整内部日志。用于复现问题的输入应当是合成样例或经过脱敏处理的文本。

需要报告的问题建议提供的信息
工具输出错误页面 URL、浏览器名称、脱敏输入、期望输出、实际输出。
页面内容错误页面 URL、具体标题或段落、你认为需要更正的原因。
广告或隐私问题页面 URL、问题描述、浏览器设置，不要附带未遮挡的私人信息。
功能建议使用场景、输入样例、希望得到的输出、为什么现有工具不能解决。

推荐反馈格式

Page URL: https://ymirtool.com/json/
Browser / device: Chrome on desktop
Problem type: tool output / content / privacy / ad / broken link
Sample input: use synthetic or redacted data only
Expected result: describe the intended output
Actual result: describe what happened
Impact: low / medium / high

这种格式可以帮助我们复现问题，避免邮件来回确认，也能减少用户误发敏感资料的风险。

常见问题

能否帮我处理私密文件？

不建议通过邮件发送私密文件。请先构造匿名样例，或只描述错误现象和字段结构。

多久会回复？

我们会优先处理影响核心工具可用性、隐私政策、广告展示和断链的问题，但无法保证所有建议都会被采纳。

可以申请删除或更正信息吗？

可以。请说明相关页面、请求类型和必要背景。不要在首次邮件中附带不必要的敏感资料。

处理优先级说明

反馈会按影响范围排序。核心工具无法使用、隐私政策问题、广告遮挡内容、站内断链和 sitemap/canonical 错误会优先处理；纯新增功能建议会进入后续维护清单。为了避免误判，请尽量提供可复现步骤，而不是只描述“不能用”。如果问题只在特定浏览器扩展、公司代理、翻译插件或移动端 WebView 中出现，请在邮件中注明。

提交反馈后，请保留原始页面 URL 和脱敏样例。我们可能根据反馈修正文案、补充 FAQ、调整内链、移除不合适的广告位置或把低质量长尾页继续保留为 noindex。任何涉及个人信息、客户信息或生产系统的材料都应先脱敏。
