What to include when contacting us

Use the contact channel for bug reports, wording issues, broken links, privacy questions, AdSense or advertising concerns, and suggestions for improving existing tools. The most useful reports are specific and reproducible: include the page URL, browser name, device type, a short non-sensitive input, the expected result, and the actual result you observed.

Bug report format

A good report avoids private data. Replace real tokens, customer names, internal domains, and credentials with synthetic values. Describe the workflow in order: where you pasted the input, which button you clicked, what output appeared, and whether refreshing the page changed the behavior.

Content feedback

If a guide is unclear, mention the paragraph or heading that caused confusion. If a tool needs a better example, include the type of scenario: API debugging, encoding compatibility, text comparison, timestamp conversion, reference lookup, or unit conversion. This helps us improve the page without adding generic filler.

Advertising and policy reports

If an ad placement, cookie notice, or policy page seems incorrect, include the visible page URL and a concise description. Do not send screenshots containing private information unless you have redacted the sensitive parts first.

如何提交可处理的反馈

有效反馈应包含页面 URL、设备或浏览器、非敏感样例输入、预期结果和实际结果。不要发送完整生产日志、密钥、客户数据或内部接口地址。如果反馈涉及文案或指南，请指出具体标题或段落；如果涉及工具行为，请说明按钮、输入格式和复制结果。
