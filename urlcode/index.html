Compact URL Component Encoder

Encode or decode a single URL component with encodeURIComponent-style behavior. Use the main URL tool for full URLs, parameters, and double-encoding checks.

Component scope

This compact page is for a single query value, path segment, or fragment value. It is not a full URL parser. Encoding an entire URL can also encode separators such as :, /, ?, and &, changing its structure.

  • Encode a parameter value before joining it to a query string.
  • Decode once, inspect the result, and only decode again when the source is known to be double-encoded.
  • A plus sign may mean a literal + or a space in form encoding; confirm the source format.
