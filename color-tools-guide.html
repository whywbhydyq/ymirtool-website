颜色工具适合网页设计、前端样式调试、品牌素材整理和图片配色参考。常见任务包括 RGB 与 HEX 互转、复制颜色值、快速查看颜色效果和生成基础配色。

颜色工具指南

输入 HEX 或 RGB 颜色值，转换格式并用于网页、设计或调试。

打开 HEX/RGB 转换工具

常用入口

  • RGB 颜色转换：适合在 CSS、设计稿和配置文件之间转换颜色值。
  • 在线调色板：适合快速选择颜色并复制色值。
  • Bootstrap 字体图标：适合查找图标类名和搭配界面颜色。

使用建议

正式页面上线前，建议检查颜色对比度，保证文字和背景之间有足够可读性。品牌色、警示色和按钮色应保持一致，避免同一个功能在不同页面使用完全不同的颜色。
