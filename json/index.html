How to use this tool / 使用说明

Use this tool for API responses, logs, configuration snippets, and JSON samples that need readable indentation or quick validation.

Common JSON errors include trailing commas, single quotes, comments, missing quotes around keys, or receiving an HTML error page instead of JSON.

Privacy note / 隐私说明

Most text, encoding, hashing, and formatting actions on this page run in your browser. Avoid pasting secrets, production credentials, private keys, or sensitive personal data into any online tool.

FAQ / 常见问题

Is this JSON uploaded?

No. Formatting, validation, and minification run in your browser.

Can this fix invalid JSON automatically?

No. It reports parsing errors so you can correct the source safely.

Why does pasted API output fail?

It may be JSONP, HTML, or a configuration format that is not strict JSON.
