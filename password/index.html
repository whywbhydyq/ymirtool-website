How to use this tool / 使用说明

Use longer passwords with mixed character sets when the target service allows them. A password manager is usually safer than memorizing generated strings.

Generation happens in your browser. Do not reuse passwords across important accounts.

Privacy note / 隐私说明

Most text, encoding, hashing, and formatting actions on this page run in your browser. Avoid pasting secrets, production credentials, private keys, or sensitive personal data into any online tool.

FAQ / 常见问题

Does this upload generated passwords?

No. Generation happens in your browser.

What length should I use?

Use at least 16 characters for most new passwords, and longer for sensitive accounts.

Should I store passwords here?

No. Copy the result into a trusted password manager.
