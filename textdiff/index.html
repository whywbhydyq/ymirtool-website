Use cases and limits

Use this tool for drafts, configuration snippets, short documents, release notes, and small text changes where line-level comparison is enough.

For large files, binary files, or repository-level code review, use a dedicated diff tool or Git. This page focuses on quick pasted-text comparison.

FAQ

What does this text diff compare?

It compares the two inputs line by line and summarizes added, removed, and changed lines.

Can it compare files or folders?

No. This page is for pasted text blocks. Use Git or a desktop diff tool for files, folders, or large codebases.

Why are word-level changes not highlighted?

This tool currently reports line-level differences. It is designed for quick summaries rather than full document review.
